## P2 进度（2026-09-21）

compact 已接通会话服务的预演与实际压缩，展示结果并拒绝版本冲突。dry-run 不写快照，实际压缩保留规范消息历史。上下文圆环与 /context 共用详情、刷新时间和估算来源；Codex 未提供的用量保持未知。

模型弹层支持搜索，使用共享的原生/配置模型目录及 Codex 发现结果，校验模型与强度组合。任务临时选择与显式保存默认值分开；带参数的 /effort 按 TUI 语义保存默认值。内置条目来自现有代码的整合，不代表重新验证了真实提供商能力。历史任务按标题与工作区搜索，恢复继续执行规范路径边界检查，只有成功后才清理临时状态。

验证：118 项相关测试通过，6 项可选真实调用测试跳过；最后的默认选择防护修改后另有 27 项 Agent/Codex 测试通过。根级检查、桌面构建、71 项确定性评估及打包安装验证通过。Electron 完成 32 张场景截图，新增模型、上下文与权限检查。详见[验收记录](design-qa.md)。未验证真实提供商调用，未更新已安装应用，未提交或发布。

## P1 执行进度（2026-09-20）

W04—W07 已完成。16 项命令目录与参数解析移入私有 `@forge/application/slash-commands`，CLI 兼容导出并接入解析；桌面帮助和菜单从同一目录生成，平台支持标签由桌面补充。

命令拼写遵循 TUI 大小写规则，effort 参数可忽略大小写。支持解析与补全 `/compact --dry-run`、`/effort <level>`；其桌面执行仍待 P2，当前明确返回未接入，不调用模型。路由返回界面、只读、管理、错误或平台不适用的结构化结果。

菜单具备 combobox/listbox 关联、选项 ID、可见选中项、Tab/Enter/Esc 与 IME 保护。非法命令保留草稿，可显式选择作为普通消息发送，绝不自动降级。异步管理命令使用即时 pending 锁防止重复提交，完成后不会清除期间新编辑的草稿。运行中 help/context 可用，修改操作返回 busy；Agent 的活动运行校验有新增回归测试。

验证：112 项相关测试通过，6 项 opt-in live 测试跳过；根级检查、桌面构建、71 项确定性评估与打包安装验证通过。Electron 29 个截图场景及新增键盘、补全、错误与 IME 检查通过。见 [QA](design-qa.md)。未提交或发布。

下一阶段为 P2（W08—W13）。new/clear 授权差异、compact dry-run 实际执行、上下文详情、权限撤销、模型/强度管理和搜索恢复仍按 P2 验收，不因本阶段解析成功而标记功能完成。

## 当前基线与缺口

以下基于当前工作区源码核对；现有未提交修改也属于本次基线，后续开发不得覆盖。

| 区域 | 当前实现 | 下一步缺口 |
| --- | --- | --- |
| 框架 | 顶部目录、侧栏内折叠、收起后铁砧入口、设置内主题 | 窄窗口、长标题、展开右栏时的布局精修 |
| 输入框 | 带标签的引擎/模型、权限、上下文圆环 | 搜索模型、能力与错误状态、用量解释和控件分组 |
| 命令 | 独立桌面目录、菜单和常用操作 | 全部参数被拒；与 TUI 共用目录及语义尚未完成 |
| 会话 | 后端 reset；compact、历史恢复已有服务 | new/clear 授权语义、dry-run、冲突和草稿测试 |
| 管理 | login/plugins 跳转现有设置；permissions 聚焦下拉框 | 不能视为完整登录、插件管理和授权撤销兼容 |
| 未连接命令 | resources/logout/delete-model/effort 明确提示未接入 | 共享管理服务和专用界面 |
| 平台 | exit 调用窗口关闭；update-dismiss 标注不适用 | 运行中关闭、取消失败和平台适用性验收 |

## 实施顺序

按 P0 → P1 → P2 → P3 → P4 执行，每阶段形成可运行结果和验收记录。任务编号用于交接，不替代既有 D 系列里程碑。实现、提交和发布分别记录，完成阶段不自动代表发布。

### P0：建立稳定基线与拆分界面

- W01：复核工作区差异；记录根级检查失败的具体文件。上一轮 `pnpm check` 被独立 `design/prototype` 格式问题阻塞，执行时重新验证；若仍存在，单独处理该目录的格式修复或合理的检查边界，不关闭生产源码规则来消除报错。
- W02：提取 WorkspaceHeader、ComposerControls、ModelSelector、SlashCommandMenu、SettingsView；业务路由与 JSX 分离。保留现有事件流、审批、取消和文件预览接口。
- W03：整理 v2 CSS 到明确的组件区域，移除被替代的重复规则；不大规模重写全站样式。

验收：拆分前后相同样例截图无意外变化；任务切换、草稿保留、主题记忆、侧栏/面板交互通过；类型检查和相关测试通过。根级检查结果必须明确归因，不能只报定向检查成功。

### P1：命令基础设施与输入可靠性

- W04：在私有共享应用层建立无 React/Ink/Electron 依赖的命令描述及解析。先读取 TUI 各处理器的实际参数规则，不把桌面当前正则当作标准。CLI 保留兼容导出。
- W05：返回结构化结果：打开界面、操作成功、失败、不适用；描述与执行权限分离。菜单、帮助、TUI 使用同一份命令目录。
- W06：实现 combobox/listbox 关联、选中项滚动可见、焦点恢复、IME 保护和参数补全。未知命令保留草稿；提供明确的“作为普通消息发送”，支持以 `/` 开头的路径或普通文本，禁止自动降级发送。
- W07：按命令性质区分运行中可用性。只读帮助可打开；会话/配置修改由 Agent 再次校验。pending 阻止重复提交，失败保留原草稿。

验收：16 个名称两端一致；合法/非法参数、大小写、路径、URL、代码块均有测试；命令错误绝不触发模型；键盘能访问超出菜单视口的最后一项。

### P2：会话、权限与模型闭环

- W08：分别核对 new/clear 与 TUI 的上下文、历史、授权语义。当前桌面没有跨运行授权缓存时明确说明差异，不为模仿界面新增授权。验证 reset 后再次拉取 state 不恢复旧活动上下文，磁盘历史仍可 resume。
- W09：实现 compact 参数与 dry-run，展示压缩前后结果；延续会话锁及修订冲突检查。dry-run 不写入快照/检查点。
- W10：context 打开统一详情视图，展示估算来源、预算、刷新时机和未知状态。Codex 没有可信遥测时继续显示未知，不用 Forge 包装层数据冒充 Codex 用量。
- W11：权限策略选择与会话授权查看/撤销分开。保留 Native safe 和 Codex read-only 的差异；验证 workspace-write 不会绕过仍需审批的操作。撤销只处理实际存在的授权。
- W12：模型弹层支持搜索、当前项、空列表、加载失败和重试；区分任务临时选择与持久默认配置。effort 从当前引擎/模型能力获取并校验；切换引擎不得静默携带无效模型或强度。
- W13：resume 增加搜索、工作区边界提示和恢复失败反馈；切换清理瞬时预览、运行状态与相关授权，保留按任务隔离的草稿。

验收：两引擎分别验证策略传递和无效值拒绝；模型/强度读写有测试；压缩冲突及 dry-run 无写入有证据；失败不能显示成功。真实提供商请求单列验证，不以 fixture 代替。

### P3：管理命令与设置完善

- W14：login/logout 选择明确引擎和提供商，复用现有认证服务；处理取消、失败和过期。退出目标不得清除另一引擎凭证，密钥不得进入渲染器状态。
- W15：delete-model 使用明确模型对象和确认界面；复用配置写入规则，删除活动/默认模型时有可解释的后续选择，失败保持原配置。
- W16：plugins 区分发现、安装、启用和配置；现有 web 设置只是其中一部分。resources 提供只读 Skills/资源诊断，发现不等于授权执行。继续保持插件显式启用与网络审批边界。
- W17：exit 复用正常 Electron 退出流程，覆盖活动运行、取消超时和未发送草稿；update-dismiss 没有对应桌面提示时返回明确“不适用”，不得伪造版本状态。

验收：16 项兼容矩阵逐条标记“已验证 / 部分实现 / 平台不适用 / 未完成”，每项关联测试或手工步骤；跳转 Settings 不算该管理命令已完成。

### P4：视觉、无障碍与交付验收

- W18：逐图对照间距、字号、消息宽度、边框、菜单密度和品牌比例；精修右栏展开后的输入框换行、长模型名、空历史、加载/失败/审批状态。现有路径预览与目标文件树的差距独立记录；若实现树，复用主进程文件边界、按需加载和文件数量限制。
- W19：覆盖中文/英文 × 深色/浅色，补充跟随系统、侧栏收起、右栏展开、设置、无对话、命令、运行和错误状态。1100×728 与 840 px 窄窗口重点检查，无横向溢出，焦点清晰，键盘操作可完成。
- W20：同步中英文说明与 QA，保留原参考图和历史证据；真实截图与设计稿明确分开。所有阶段状态按实际结果更新。

验收：完整工作流走通“选择工作区 → 配置引擎/模型/权限 → 发起任务 → 审批/停止 → 查看结果 → 新建/恢复”；可读截图、测试结果及已知限制均可追溯。

## 检查与交付规则

| 变化范围 | 必须执行 |
| --- | --- |
| TypeScript/工作流 | 定向 Vitest、`CI=true pnpm check`、桌面构建 |
| 协议/会话/权限跨层 | 增加 `CI=true pnpm eval:deterministic`；检查主进程、Agent 与渲染器边界 |
| Markdown/索引 | `CI=true pnpm check:docs` |
| UI | 构建后运行 Electron acceptance；查看截图，而非只看脚本退出码 |
| 打包资源/公共产物 | `CI=true pnpm package:verify`；安装包验证单列 |

每个阶段交付：变更摘要、相关测试、实际截图（有视觉变化时）、命令矩阵更新、未解决项。不要把上一轮 15 项测试/71 项评估/29 个场景当作下一轮结果，修改后按影响重新验证。

不在本计划中默认执行：Git 提交/合并、更新已安装 App、签名、公证、发布，以及新增 /plan 或 /goal 产品模式。若后续要求发布，另行执行发布清单。
